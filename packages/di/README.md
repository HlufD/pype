# pyper-di

A dependency injection container for [Pype](../core) and Node.js.

**Status: not started.** This package is an empty placeholder in the Pype
monorepo and is not published to npm yet (`"private": true`).

## Development

From the repository root:

```sh
npm run build -w pyper-di
npm run typecheck -w pyper-di
npm test -w pyper-di
```
